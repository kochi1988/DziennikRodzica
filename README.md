# Dziennik Rodzica

Dziennik Rodzica to aplikacja na Androida ułatwiająca rodzicom dostęp do najważniejszych informacji z dziennika elektronicznego LIBRUS.

Aplikacja umożliwia korzystanie z danych szkolnych w jednym, prostym interfejsie oraz automatycznie sprawdza dostępność nowych informacji i aktualizacji aplikacji.

## Instalacja

Najnowszą wersję aplikacji można pobrać tutaj:

### [Pobierz Dziennik Rodzica](https://kochi1988.github.io/DziennikRodzica/)

Bezpośredni link do najnowszego pliku APK:

https://github.com/kochi1988/DziennikRodzica/releases/latest/download/DziennikRodzica.apk

Aplikacja jest dystrybuowana poza Google Play.

Przy pierwszej instalacji Android może poprosić o zezwolenie przeglądarce na instalowanie aplikacji z nieznanych źródeł.

## Aktualizacje

Dziennik Rodzica posiada własny system aktualizacji.

Po zainstalowaniu aplikacja:

- automatycznie sprawdza dostępność nowych wersji,
- może powiadomić o nowej wersji w tle,
- pobiera aktualizację bezpośrednio z GitHub Releases,
- weryfikuje integralność pobranego pliku,
- uruchamia systemowy instalator Androida.

Nie trzeba ponownie pobierać aplikacji ręcznie przy każdej kolejnej wersji.

## Wymagania

- Android 7.0 lub nowszy
- dostęp do Internetu
- aktywne konto LIBRUS Synergia

## Repozytorium

To repozytorium służy do publicznej dystrybucji aplikacji Dziennik Rodzica oraz publikowania informacji potrzebnych do automatycznych aktualizacji.

Kod źródłowy aplikacji nie jest publikowany w tym repozytorium.

## Informacja

Dziennik Rodzica jest niezależną aplikacją i nie jest oficjalną aplikacją ani produktem firmy LIBRUS.
